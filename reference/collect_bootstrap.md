# Collect a non-blocking bootstrap job

Collect a non-blocking bootstrap job

## Usage

``` r
collect_bootstrap(job)
```

## Arguments

- job:

  A `qdr_bootstrap_job` returned by
  [`bootstrap_dose_response_async()`](https://seanthimons.github.io/singlehit/reference/bootstrap_dose_response_async.md).

## Value

A completed `qdr_bootstrap` tibble.
