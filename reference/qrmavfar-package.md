# qrmavfar: microbial dose-response model fitting

Fits exponential and approximate beta-Poisson dose-response models to
grouped binomial microbial response data. Provides trend tests, model
diagnostics, bootstrap uncertainty estimates, effective doses, and
publication-ready dose-response plots.
